🔑 Configurer votre base Firebase (pour GitHub Pages)

Collez ici l'objet firebaseConfig de votre projet Firebase gratuit pour activer la synchronisation téléphone ↔ ordinateur sur votre site GitHub Pages :

👁️1. Lien Famille (Lecture seule uniquement)

Vos proches voient tout l'arbre, les photos et les frises en temps réel, mais ne peuvent rien modifier ni supprimer.

📱💻2. Votre lien privé (Édition Téléphone & Ordi)

Ouvrez ce lien secret sur votre téléphone pour modifier le même arbre depuis vos deux appareils.

🌐 Étapes pour synchroniser Téléphone & Ordinateur
  1. Collez votre configuration Firebase ci-dessus (ou dans la constante DEFAULT_FIREBASE_CONFIG de index.html sur GitHub).
  2. Importez votre fichier .ged sur l'ordinateur : il est envoyé automatiquement dans le nuage.
  3. Copiez le Lien privé (#2) et ouvrez-le sur votre téléphone pour modifier le même arbre en temps réel, et envoyez le Lien Famille (#1) à vos proches !
